Reproducing the publication#

This section describes how to reproduce the figures, tables, sensitivity studies, and computational results in the pofff paper.

The workflows use plopm for visualization. Unless stated otherwise, run all commands from the pofff repository root. Each workflow writes to a directory named after the corresponding figure or group of figures.

Prerequisites#

Tip

You can install plopm by executing in the terminal:

pip install git+https://github.com/cssr-tools/plopm.git

Figure 3: geology and thickness#

pofff -i examples/input.toml -o figure3 -f none
plopm -i figure3/FIGURe3 -c '101;64;147 81;124;66 181;73;57 193;127;97 127;148;191 193;147;56'  -cbt '[G, F, E, D, C, ESF]' -v 'pvtnum - 1 - satnum' -ge 'black,1e-2' -hide 1,1,0,1 -fs 20,15 -o figure3 -fn figure3a -fz 20 -cbl 'Sand'
plopm -i figure3/FIGURe3 -v 'multx * 1.75' -ge 'black,1e-2' -hide 1,1,0,1 -fs 20,15 -cbl 'Thickness map [cm]' -cbf .2f -cbn 5 -fz 20 -o figure3 -fn figure3b

Figure 4: SPE11A grid comparison#

Figure 4 requires running the SPE11A cases using pyopmspe11, which uses the simulation grid. You might need to edit the configuration files to adjust the computational resources to your machine (e.g., r3_cp_1cmish_capmax2500Pa.toml is run with 32 CPUs).

Tip

You can install pyopmspe11 by executing in the terminal:

pip install git+https://github.com/OPM/pyopmspe11.git

mkdir figure4 && cd figure4
curl -O https://raw.githubusercontent.com/OPM/pyopmspe11/refs/heads/main/benchmark/spe11a/r2_Cart_1cm_capmax2500Pa.toml
curl -O https://raw.githubusercontent.com/OPM/pyopmspe11/refs/heads/main/benchmark/spe11a/r3_cp_1cmish_capmax2500Pa.toml
curl -O https://raw.githubusercontent.com/OPM/pyopmspe11/refs/heads/main/benchmark/spe11a/r4_Cart_1mm_capmax2500Pa.toml
curl -O https://raw.githubusercontent.com/OPM/pyopmspe11/refs/heads/main/benchmark/spe11a/r5_Cart_1mm_capmax2500Pa_strictol.toml
pyopmspe11 -i r2_Cart_1cm_capmax2500Pa.toml -o r2_Cart_1cm_capmax2500Pa -t 1 -r 280,1,120 -w 0.16666666666666666
pyopmspe11 -i r3_cp_1cmish_capmax2500Pa.toml -o r3_cp_1cmish_capmax2500Pa -t 1 -r 280,1,120 -w 0.16666666666666666
pyopmspe11 -i r4_Cart_1mm_capmax2500Pa.toml -o r4_Cart_1mm_capmax2500Pa -t 1 -r 280,1,120 -w 0.16666666666666666
pyopmspe11 -i r5_Cart_1mm_capmax2500Pa_strictol.toml -o r5_Cart_1mm_capmax2500Pa_strictol -t 1 -r 280,1,120 -w 0.16666666666666666
plopm -v xco2l -r 53 -mv satnum -mt 7e-5 -i 'r2_Cart_1cm_capmax2500Pa/flow/R2_CART_1CM_CAPMAX2500PA r3_cp_1cmish_capmax2500Pa/flow/R3_CP_1CMISH_CAPMAX2500PA r4_Cart_1mm_capmax2500Pa/flow/R4_CART_1MM_CAPMAX2500PA r5_Cart_1mm_capmax2500Pa_strictol/flow/R5_CART_1MM_CAPMAX2500PA_STRICTOL' -cbn 3 -xnt 8 -cbl 'OPM results for SPE11A: CO$_2$ mass fraction (liquid phase) after 2 days' -fs 16,6.5 -t "(a) Cartesian grid 1cm  (b) Corner-point grid 1cmish  (c) Cartesian grid 1mm  (d) Cartesian grid 1mm stricter tolerances" -yu cm -xu cm -yf .0f -xf .0f -fz 16 -fn figure4 -cbf .2e -st 0 -sg 2,2 -cbp 0.35,0.97,0.3,0.02 -rdl 1 -c '#9ca245 #9da347 #9fa44a #a0a64d #a2a750 #a3a953 #a5aa56 #a6ac59 #a8ad5c #a9af5f #abb062 #adb164 #aeb367 #b0b46a #b1b66d #b3b770 #b4b973 #b6ba76 #b7bc79 #b9bd7c #babf7f #bcc082 #bec184 #bfc387 #c1c48a #c2c68d #c4c790 #c5c993 #c7ca96 #c8cc99 #cacd9c #cbcf9f #cdd0a2 #cfd1a4 #d0d3a7 #d2d4aa #d3d6ad #d5d7b0 #d6d9b3 #d8dab6 #d9dcb9 #dbddbc #dcdfbf #dee0c1 #e0e1c4 #e1e3c7 #e3e4ca #e4e6cd #e6e7d0 #e7e9d3 #e9ead6 #eaecd9 #eceddc #edefdf #eff0e1 #f1f1e4 #f2f3e7 #f4f4ea #f5f6ed #f7f7f0 #f8f9f3 #fafaf6 #fbfcf9 #fdfdfc #ffffff #fefbfb #fdf7f7 #fcf3f3 #fbefef #faebeb #f9e7e7 #f8e3e3 #f7e0e0 #f6dcdc #f5d8d8 #f4d4d4 #f3d0d0 #f2cccc #f1c8c8 #f0c5c5 #efc1c1 #eebdbd #edb9b9 #ecb5b5 #ebb1b1 #eaadad #e9aaaa #e8a6a6 #e7a2a2 #e69e9e #e59a9a #e49696 #e39292 #e28f8f #e18b8b #e08787 #df8383 #de7f7f #dd7b7b #dc7777 #db7474 #da7070 #d96c6c #d86868 #d76464 #d66060 #d55c5c #d45959 #d35555 #d25151 #d14d4d #d04949 #cf4545 #ce4141 #cd3e3e #cc3a3a #cb3636 #ca3232 #c92e2e #c82a2a #c72626 #c62323 #c51f1f #c41b1b #c31717 #c21313 #c10f0f #c00b0b'

Using submitted SPE11A CSV data#

A similar figure without the need of running the simulations (not showing the sands in the background and using the reporting grid) can be obtained by downloading the SPE11A benchmark data in csv format available at this website (the submitted benchmark data does not include the r5_Cart_1mm_capmax2500Pa_strictol.toml results):

mkdir figure4 && cd figure4
curl -L -O https://darus.uni-stuttgart.de/api/access/datafile/375719
unzip 375719
curl -L -O https://darus.uni-stuttgart.de/api/access/datafile/375716
unzip 375716
curl -L -O https://darus.uni-stuttgart.de/api/access/datafile/375707
unzip 375707
plopm -v xco2l -i 'spe11a/opm2/spe11a_spatial_map_48h spe11a/opm3/spe11a_spatial_map_48h spe11a/opm4/spe11a_spatial_map_48h' -cc "1,2,5;1,2,5;1,2,5" -c cet_diverging_gwr_55_95_c38 -cbn 3 -xnt 8 -cbl 'OPM results for SPE11A: CO$_2$ mass fraction (liquid phase) after 2 days' -fs 16,6.5 -t "(a) Cartesian grid 1cm  (b) Corner-point grid 1cmish  (c) Cartesian grid 1mm" -yu cm -xu cm -yf .0f -xf .0f -fz 16 -fn figure4ish -cbf .2e -st 0 -sg 2,2 -cbp 0.35,0.97,0.3,0.02 -rdl 1

Figures 5 to 8 and Table 4#

Figures 5 (g, h, i), 6, 7, and 8 (in addition, the values on Table 4 are obtained from the generated error_table_satmin-0.01_conmin-0.1.csv):

mkdir figures5-8 && cd figures5-8
pofff -m fair

where fair attempts to aling with these principles.

Figures 10 and 11 and Table 5#

Similarly, Figures 10 (g, h, i) and 11 (in addition, the values on Table 5 are obtained from the generated error_table_satmin-0.01_conmin-0.05.csv)

mkdir figures10-11 && cd figures10-11
pofff -m fair -c 0.05

See Tutorial to add a customized simulation to the paper comparisons.

MPI acceleration#

Tip

If your OPM Flow supports MPI, then to speed up the simulations you could change Line 3 in results.toml and appendixb.toml to:

flow="mpirun -np 8 flow --newton-min-iterations=1 --solver-max-restarts=20 --time-step-control=newtoniterationcount --solver-growth-factor=1.6 --linear-solver=cpr_trueimpes --time-step-control-growth-rate=1.1 --solver-restart-factor=0.5 --time-step-control-decay-rate=0.65 --enable-opm-rst-file=true"

The values in the flags were manually set trying to speed up the simulations. Then, you could also try to run the cases with different flags.

Appendix C: computational details#

For the computational-details results in Appendix C, we use the templated configuration file appendixc.mako, together with Python commands, which gives flexibility to generate the different cases.

Sensitivity to setup choices#

The Wasserstein distance (obtained from the generated error_table_satmin-0.01_conmin-0.1.csv) for the base case and random seed for the sensitivity study regarding setup choices in Table 8 can be generated by executing the sensitivity.py script (if you have a Mac as well, then execute the script in there to see the sensitivity to the operating system).

Table 7 and Figure 12: profiling#

The values in Table 7 and Figure 12 can be generated by (increase or decrease the number of cores to adapt to your interest and computer limitations):

cd publication && python3 profiling.py

Table 9: accuracy-time trade-off#

For the accuracy-time trade-off in Table 9, run:

cd publication && python3 accuracy.py

Warning

These scripts are set to run with 64 cores, then you should edit them if your machine has fewer available CPUs.

Reproduce all publication results#

The maintained publication.sh script reproduces the publication workflows described on this page.

. ./tests/scripts/publication.sh

By default, the script runs the cases with 64 cores. To run the cases with 16 cores and a coarser grid, use:

. ./tests/scripts/publication.sh 16
